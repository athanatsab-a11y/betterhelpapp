# AFO — σελίδα πώλησης (ελληνικά)

Μονοσέλιδο site για την πώληση της μπάλας πυρόσβεσης **AFO / Auto Fire Off** σε ελληνικό κοινό.
Ένα αρχείο, χωρίς build, χωρίς εξαρτήσεις: `index.html` (HTML + CSS + JS μαζί).

## Προεπισκόπηση

```bash
python3 -m http.server 8080 --directory sites/afo
# ή
npx serve sites/afo
```

Ανοίγει και με διπλό κλικ στο `index.html` (οι γραμματοσειρές Google Fonts θέλουν σύνδεση).

## Τι πρέπει να αλλάξετε πριν πάει ζωντανά

| Πού | Τι |
| --- | --- |
| `SHOP` (μπλοκ στην αρχή του `<script>`) | επωνυμία, email, τηλέφωνο, μεταφορικά, όριο δωρεάν αποστολής, επιβάρυνση αντικαταβολής |
| `PACKS` (ίδιο σημείο) και το τμήμα «Πακέτα» | τιμές — οι σημερινές (34,90 / 64,90 / 119,00 €) είναι ενδεικτικές |
| `<footer>` | διεύθυνση έδρας, ΑΦΜ, ΔΟΥ, ΓΕΜΗ, τηλέφωνο, email. Το ΠΔ 131/2003 απαιτεί να είναι ορατά τα στοιχεία της επιχείρησης |
| πλαίσιο «Σημείωση για τον πωλητή» στο footer | **σβήστε το** αφού συμπληρώσετε τα παραπάνω |
| `ORDER_ENDPOINT` | βάλτε URL όταν αποκτήσετε backend ή υπηρεσία φορμών· όσο είναι `null`, η φόρμα ετοιμάζει την παραγγελία ως email προς το κατάστημα |
| το SVG της μπάλας στο hero | αντικαταστήστε με πραγματικές φωτογραφίες προϊόντος (`<img src="..." alt="...">`) |

## Πώς δουλεύει η παραγγελία

Η φόρμα ελέγχει ονοματεπώνυμο, κινητό (69XXXXXXXX ή σταθερό 10 ψηφίων), email, διεύθυνση,
ΤΚ 5 ψηφίων, πόλη και προαιρετικό ΑΦΜ 9 ψηφίων. Το σύνολο υπολογίζεται ζωντανά (προϊόντα +
μεταφορικά + αντικαταβολή). Με `ORDER_ENDPOINT = null` εμφανίζεται σύνοψη με κουμπί
«Αποστολή με email» (`mailto:`) και κουμπί κλήσης — δεν φεύγει τίποτα σε τρίτο server και
δεν ζητούνται στοιχεία κάρτας.

## Περιεχόμενο

Η σελίδα λέει ρητά ότι η μπάλα **δεν αντικαθιστά πιστοποιημένο πυροσβεστήρα ΕΝ 3**, δεν
χρησιμοποιείται σε φωτιά λαδιού (κατηγορία F) ή μετάλλων (D), και ότι πρώτα καλείται το 199.
Μην αφαιρέσετε αυτά τα σημεία: προστατεύουν και τον αγοραστή και τον πωλητή, και τα τεχνικά
μεγέθη δίνονται ως «στοιχεία κατασκευαστή». Αν έχετε πιστοποιητικά της παρτίδας σας,
ανεβάστε τα και συνδέστε τα από το τεχνικό δελτίο.
