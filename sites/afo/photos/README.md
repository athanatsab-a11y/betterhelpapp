# Φωτογραφίες προϊόντος

Βάλτε εδώ τα αρχεία σας και δηλώστε τα στον πίνακα `PHOTOS` μέσα στο `index.html`:

```js
const PHOTOS = [
  { src: "photos/1-proion.jpg",   alt: "Μπάλα πυρόσβεσης AFO σε λευκό φόντο" },
  { src: "photos/2-topothetisi.jpg", alt: "Η μπάλα στη βάση της, πάνω από ηλεκτρικό πίνακα" },
  { src: "photos/3-megethos.jpg", alt: "Η μπάλα στο χέρι, για σύγκριση μεγέθους" },
  { src: "photos/4-syskevasia.jpg", alt: "Περιεχόμενα συσκευασίας: μπάλα, βάση, οδηγίες" }
];
```

Όπου αφήσετε `null`, εμφανίζεται η αντίστοιχη σχεδιαστική απεικόνιση.

## Οι τέσσερις λήψεις που χρειάζεστε

| # | Λήψη | Γιατί πουλάει |
| --- | --- | --- |
| 1 | Το προϊόν σε λευκό ή ανοιχτό γκρι φόντο, ολόκληρο, με φυσικό φως | η βασική εικόνα καταλόγου — πρέπει να δείχνει **ακριβώς** αυτό που στέλνετε |
| 2 | Τοποθετημένη στη βάση της, πάνω από πραγματικό ηλεκτρικό πίνακα | δείχνει πού μπαίνει· απαντά στο «και πού το βάζω;» |
| 3 | Στο χέρι ή δίπλα σε γνωστό αντικείμενο | το μέγεθος δεν γίνεται αντιληπτό από τα χιλιοστά |
| 4 | Ανοιγμένη συσκευασία με μπάλα, βάση και έντυπο οδηγιών | μειώνει τον φόβο «τι θα παραλάβω τελικά;» |

## Τεχνικά

- **Μέγεθος**: τετράγωνες, ~1200×1200 px. Το gallery τις προσαρμόζει (`object-fit: contain`).
- **Βάρος**: κάτω από 200 KB η καθεμία — συμπιέστε σε WebP ή JPEG ποιότητας 80.
- **Δεν χρησιμοποιείτε φωτογραφίες τρίτων** (Amazon, AliExpress, κατάλογοι προμηθευτή) χωρίς άδεια:
  είναι πνευματική ιδιοκτησία τους. Φωτογραφίστε το δικό σας απόθεμα.
- Η εικόνα πρέπει να απεικονίζει **το προϊόν που πραγματικά παραδίδετε**· διαφορετική εμφάνιση από
  την παραδοθείσα συσκευασία θεωρείται παραπλανητική εμπορική πρακτική.
