# MindBridge

Πλατφόρμα online ψυχοθεραπείας με τις λειτουργίες του BetterHelp: ερωτηματολόγιο εισαγωγής,
αυτόματη αντιστοίχιση με θεραπευτή, ιδιωτικό δωμάτιο μηνυμάτων σε πραγματικό χρόνο, live συνεδρίες
(βίντεο / τηλέφωνο / chat), ημερολόγιο διάθεσης, φύλλα εργασίας, groupinars, συνδρομές με οικονομική
ενίσχυση και ξεχωριστό portal για τους θεραπευτές.

> Εκπαιδευτικό demo. Δεν παρέχει πραγματικές υπηρεσίες ψυχικής υγείας και δεν πρέπει να χρησιμοποιηθεί
> ως τέτοιο. Σε επείγον περιστατικό: **112** ή Γραμμή Παρέμβασης για την Αυτοκτονία **1018**.

## Λειτουργίες

**Για τα μέλη**
- Ερωτηματολόγιο 14 βημάτων (και χωρίς λογαριασμό) με ανίχνευση επιπέδου κινδύνου και προβολή
  γραμμών άμεσης βοήθειας όταν χρειάζεται.
- Αλγόριθμος αντιστοίχισης που βαθμολογεί κάθε θεραπευτή σε εξειδίκευση, προσέγγιση, γλώσσα, φύλο,
  πνευματική διάσταση, ταχύτητα απόκρισης και φόρτο εργασίας — με εξήγηση για κάθε πρόταση.
- Εγγραφή με ψευδώνυμο, επιλογή πακέτου, mock checkout (δεν αποθηκεύονται στοιχεία κάρτας).
- Ιδιωτικό δωμάτιο θεραπείας: ασύγχρονα μηνύματα, live παράδοση μέσω WebSocket, ένδειξη «γράφει…»,
  μετρητές αδιάβαστων.
- Κράτηση live συνεδρίας 45′ από το ημερολόγιο διαθεσιμότητας του θεραπευτή, ακύρωση και
  προσομοιωμένο δωμάτιο κλήσης με χρονόμετρο.
- Ημερολόγιο με καταγραφή διάθεσης και γράφημα τάσης· επιλογή κοινοποίησης στον θεραπευτή.
- Φύλλα εργασίας (CBT/ACT) — βιβλιοθήκη και αναθέσεις από τον θεραπευτή.
- Groupinars με δήλωση συμμετοχής.
- Χρεώσεις: αλλαγή/πάγωμα/ακύρωση πακέτου, ιστορικό πληρωμών, αίτηση οικονομικής ενίσχυσης με
  κλιμακωτή έκπτωση έως 40%.
- Αλλαγή θεραπευτή χωρίς χρέωση (αυτόματη πρόταση ή χειροκίνητη επιλογή), κριτικές, ειδοποιήσεις,
  ρυθμίσεις λογαριασμού, αλλαγή κωδικού, διαγραφή λογαριασμού.

**Για τους θεραπευτές**
- Λίστα ενεργών πελατών με αδιάβαστα μηνύματα και σήμανση επιπέδου κινδύνου.
- Φάκελος πελάτη: απαντήσεις ερωτηματολογίου, κοινοποιημένες σημειώσεις ημερολογίου, φύλλα εργασίας.
- Διαχείριση διαθεσιμότητας (slots ανά τρόπο επικοινωνίας), λίστα συνεδριών, ιδιωτικές σημειώσεις.
- Επεξεργασία προφίλ: ειδικεύσεις, προσεγγίσεις, γλώσσες, μέγιστος αριθμός πελατών, χρόνος απόκρισης.

**Δημόσιο site**
Landing page, «Πώς λειτουργεί», τιμοκατάλογος με εναλλαγή περιόδου χρέωσης, κατάλογος θεραπευτών με
φίλτρα, σελίδες προφίλ με κριτικές, FAQ, κριτικές μελών, σελίδα γραμμών άμεσης βοήθειας.

## Τεχνολογίες

- **Backend**: Node.js, Express, better-sqlite3, JWT σε httpOnly cookie, bcrypt, `ws` για WebSocket.
- **Frontend**: React 18, React Router 6, Vite — χωρίς UI framework, custom design system σε CSS.
- **Βάση**: SQLite (WAL), 17 πίνακες, foreign keys ενεργά.

## Εκκίνηση

```bash
npm install          # εγκαθιστά και τις εξαρτήσεις του client
npm run seed         # γεμίζει τη βάση με 12 θεραπευτές, φύλλα εργασίας, groupinars, demo μέλος
npm run dev          # API στο :3000 και Vite dev server στο :5173
```

Για production build:

```bash
npm run build        # χτίζει το client/dist
npm start            # ο Express σερβίρει API + SPA στο :3000
```

Ρυθμίσεις: αντίγραψε το `.env.example` σε `.env` (`PORT`, `JWT_SECRET`, `DATA_DIR`).

## Δομή

```
server/
  index.js         Express app, static SPA, error handling
  db.js            Σχήμα SQLite + helper ειδοποιήσεων
  auth.js          JWT cookies, hashing, guards ρόλων
  catalog.js       Ερωτηματολόγιο, ειδικεύσεις, προσεγγίσεις, πακέτα, τιμολόγηση
  matching.js      Αλγόριθμος αντιστοίχισης και ανάθεση θεραπευτή
  realtime.js      WebSocket hub (μηνύματα, typing)
  seed.js          Αρχικά δεδομένα
  routes/          auth · intake · therapy · tools · billing
client/src/
  pages/           Δημόσιες σελίδες, /app (μέλος), /provider (θεραπευτής)
  components/      Header, Footer, κάρτες θεραπευτών, avatars
  lib/             API client, auth context, WebSocket client
tests/e2e.mjs      End-to-end έλεγχοι
```

## Σημειώσεις ασφάλειας

- Οι κωδικοί αποθηκεύονται με bcrypt· το JWT μπαίνει σε httpOnly cookie (secure σε production).
- Κάθε πρόσβαση σε δωμάτιο, συνεδρία και φάκελο πελάτη ελέγχεται ως προς τα δικαιώματα του χρήστη.
- Το checkout είναι προσομοίωση: δεν γίνεται καμία πραγματική χρέωση και δεν αποθηκεύονται στοιχεία κάρτας.
- Οι live κλήσεις είναι προσομοιωμένες· σε παραγωγή θα ενσωματωνόταν πλατφόρμα τηλεϊατρικής.
